GTS9W_BACK - Galaxy Tab S9 Wi-Fi (SM-X710) Ubuntu microSD

This partition holds the backup of THIS tablet's Android boot images
(boot, init_boot, vendor_boot, dtbo), taken by the Ubuntu installer zip
before it wrote the Ubuntu boot images.

  android-restore.zip   flash it in recovery to boot Android again
  android/              the same images and SHA256SUMS, unpacked

Do not delete them while Ubuntu is installed: they are the way back to
Android without a PC. Your Android data is never touched by the installer.

Bu bolumde, Ubuntu kurulum zip'inin Ubuntu acilis imajlarini yazmadan once
aldigi Android acilis imajlarinin yedegi var. Android'e donmek icin
recovery'de android-restore.zip dosyasini flashlayin.
